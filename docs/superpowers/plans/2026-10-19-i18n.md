# Internationalisierung de-DE / en-US – Plan

Spec: `docs/superpowers/specs/2026-10-19-i18n-design.md` · Konzept: `.superpowers/sdd/i18n-research.md` (Dateilisten und Fundstellen dort, Abschnitte 1.1 und 4).

Gate nach jeder Welle: `npm run typecheck` und `npx vitest run` grün, danach ein Commit pro Task. Jeder Umsetzer schreibt nur die genannten Dateien, committet nie und legt einen Report unter `.superpowers/sdd/2026-10-19-i18n/reports/<task>.md` ab.

Abweichung vom Konzept: UX-Audit-Dateien entfallen (Spec S1). Die Migration läuft in zwei Wellen: erst Main (Codes und Event-Typen), dann Renderer. So ist jede Welle für sich grün, und die Event-Typ-Verträge sind schon fertig, wenn die Renderer-Tasks starten.
